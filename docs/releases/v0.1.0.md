# v0.1.0

Initial version of `github.com/aliighahremanii/buildingblocks`: a reusable Go
toolkit for event-sourced, CQRS, vertical-slice services, extracted from the
YardFlow backend. This is a library, not an application framework; consumers
own their business types, composition roots, endpoints, and deployment.

## Included capabilities

- Typed command/query handlers and explicitly composed middleware, application
  errors, concurrency expectations, and correlation helpers; no global bus or
  reflection-based handler registry.
- KurrentDB (EventStoreDB) event storage, aggregate helpers, snapshots,
  upcasters, projection workers, checkpoints, and dead-letter handling.
- Postgres adapters for idempotency, dead-letter handling, sagas, and read
  helpers, plus shared infrastructure migrations exposed as an embedded
  `fs.FS`. The migration package is a source, not a migration runner.
- NATS JetStream adapters and Meilisearch client/settings reconciliation.
- HTTP/web, problem-error mapping, OpenAPI, and GraphQL helpers.
- A compiling quickstart, architecture and adoption guides, and a live
  integration gate for Postgres, KurrentDB, Meilisearch, and NATS.

## Adoption and compatibility

- Requires Go **1.26.3**. Licensed under **Apache-2.0**.
- After publication completes, pin the exact version with
  `go get github.com/aliighahremanii/buildingblocks@v0.1.0`. Use the standard
  public proxy and checksum database; no credentials, private-module exemption,
  committed `replace`, or workspace substitution are needed.
- Consumers own product-specific contracts and migration SQL, the combined
  migration ledger, and globally unique migration versions.
- While the module is `v0.x`, a minor version bump signals breaking changes.
  Published versions are immutable; corrections require a new version.
- Some operator-facing and telemetry strings retain the original product name,
  including the default `yardflow` telemetry identity. Review the README's
  known residual coupling before adoption.

These notes describe the version's scope; their presence alone does not prove
publication or public-proxy availability. Follow `docs/adoption.md` and
`docs/release.md` in the tagged source for adoption requirements and release
gates.
